Distributed ACID Transactions are not available for the C SDK.
Previously a version of {cpp} Distributed ACID Transactions was built upon the C SDK, although not exposing any C symbols explicitly. 
This has now been deprecated, and customers are recommended to explore
xref:cxx-sdk:howtos:distributed-acid-transactions-from-the-sdk.adoc[native {cpp} SDK ACID transactions].
